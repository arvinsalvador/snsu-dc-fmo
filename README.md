# SNSU-DC FMO

Facilities Management Office Work Order Management System for Surigao del Norte State University – Del Carmen Campus.

This monorepository contains the Laravel web/API application in `web/`, the Flutter mobile foundation in `mobile/`, and project documentation in `docs/`.

Phase 1 provides the development foundation. Phase 2 adds registration approval, web and API authentication, and role-based access control. Work orders remain in later phases.

Read [local setup](docs/LOCAL_SETUP.md), [architecture](docs/ARCHITECTURE.md), [workflow conventions](docs/GIT_WORKFLOW.md), and the [phase roadmap](docs/PHASES.md).
Phase 2 account and permission rules are in [authorization](docs/AUTHORIZATION.md).

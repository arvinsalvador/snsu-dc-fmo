# Version 1 release notes — candidate `v1.0.0`

This is a **proposed designation**, not a Git tag or a released deployment. The Laravel web/API implementation includes approval-gated accounts; role- and permission-based administration/delegation; requester and FMO personnel profiles/skills; campus/building/location reference data; Work Order requests with private attachments; screening, clarification, approval/disapproval and Campus Director direct authorization; multiple-person assignment; assessment and management exception review; individual work sessions, updates, evidence, continuation/waiting states, completion and verification; in-app notifications; dashboards, scoped history, CSV and browser-printable Work Orders.

The Flutter source contains a per-account SQLite task cache and durable outbox, secure token storage, assigned-only full snapshots, idempotent server operations/media uploads, and conflict-preserving retry logic. **It has not yet passed Flutter SDK, Android build, device, restart/offline, or account-switch verification in this workspace.** Native OS background scheduling and a guided conflict recovery/export flow are not implemented. Notifications are available through the API, but no Flutter notification center is implemented. These are release blockers for a field-mobile pilot, not completed features.

Version 1 does not include inventory/material stock deduction, tools, asset/QR management, preventive maintenance, recurring inspections, push notifications, advanced BI, or AI-assisted decisions. Potential Version 2 modules should be planned separately; none are part of this candidate. Formal human UAT and shared-hosting validation remain required before release.

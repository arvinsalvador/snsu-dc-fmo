# Git workflow

Permanent branches are `main` and `dev`. Development normally starts from `dev`.

Suggested temporary branch names are `feature/...`, `fix/...`, `hotfix/...`, and `chore/...`. Prefer Conventional Commit-style messages such as `feat: add request validation`, `fix: handle API timeout`, or `chore: update local tooling`.

This document describes conventions only; project owners control repository operations and releases.
